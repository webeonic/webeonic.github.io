Privacy Policy

Darwin personal assistant · last updated 28 September 2026

Darwin is a single-user assistant, self-hosted by its owner on hardware the owner controls. There are no other users and no accounts to create. This policy describes what happens to Google account data when the owner connects their own Google account to it.

Data accessed

With the owner's explicit consent, Darwin requests these Google scopes:

  • Gmail — read messages, apply labels, create drafts, and send mail on the owner's behalf.
  • Google Calendar — read calendars and events, and create or edit events.
  • Basic profile — email address and name, used only to confirm which account is connected.

Only the mailbox and calendars of the account that granted consent are accessed. Mail is sent or modified only in response to an explicit instruction from the owner.

How the data is processed

Messages and events are fetched to the owner's own server, where they are summarised into a private briefing. To produce those summaries and to extract facts, the content of messages and events may be sent to third-party AI model providers — currently OpenAI and Google Gemini — over encrypted connections, under those providers' API terms. Facts derived from this content may be stored in a private database on the same server so the assistant can recall context later.

What never happens

  • Data is never sold, rented, or used for advertising or profiling.
  • Data is never shared with any other person; the assistant has exactly one user.
  • No analytics, tracking, or third-party scripts run on this website.
  • Google data is not used to train any model.

Storage, retention and security

Data stays on the owner's server, which runs the assistant in isolated containers with restricted network egress. Access tokens are stored with owner-only file permissions and are never written to logs. Retrieved content and derived facts are kept until the owner deletes them, and the owner can erase the local database at any time.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions. Revoking immediately stops all further access to Gmail and Calendar. To also remove data already retrieved, delete the assistant's local database, or ask using the contact address below.
